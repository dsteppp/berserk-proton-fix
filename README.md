# Berserk Heroes Online: вход в 4game под Linux

[English](README.en.md)

Неофициальный патч совместимости для Steam-версии **Berserk Heroes Online** (AppID `4926310`). Помогает открыть окно входа по почте под Proton. Для обычного Linux x86_64 и Steam Deck используется один скрипт.

## Что нужно заранее

- Steam с выполненным входом в учётную запись.
- Игра, уже установленная **через Steam**. Папка установки может быть любой библиотекой Steam, в том числе на другом диске или microSD.
- Интернет для недостающих компонентов.
- Свободное место: до 3 ГБ для окружения игры плюс место для одной резервной копии существующего префикса. Если Proton ещё нет, Steam дополнительно скачает его и среду запуска.

**Заранее запускать игру не нужно.** Если вы уже запускали её с другим Proton, скрипт сохранит существующее окружение и назначит выбранный Proton сам. Закройте игру перед установкой.

Нужны Bash, Python 3, curl и стандартные команды Linux. Скрипт проверяет их наличие. Он не использует sudo, не меняет системные пакеты и не отключает защиту SteamOS. Наличие Steam само по себе не гарантирует, что все эти команды установлены в произвольном дистрибутиве.

## Установка

1. На Steam Deck перейдите в **режим рабочего стола**. На обычном Linux откройте терминал.
2. Скачайте файл `berserk-proton-fix.sh` из этого репозитория. Откройте терминал в папке со скачанным файлом.
3. Выполните:

   ```bash
   bash berserk-proton-fix.sh
   ```

4. Если Steam откроет установку Proton или Steam Linux Runtime, подтвердите её. Остальное скрипт делает сам. Если загрузка не успеет завершиться за время ожидания, дождитесь её в Steam и повторите ту же команду.
5. После сообщения о завершении запустите игру **через Steam** и войдите по почте. На Deck затем можно вернуться в игровой режим.

В свойствах игры ничего вручную выбирать не нужно: скрипт назначает Proton и добавляет `PROTON_USE_XALIA=0`, сохраняя обычные параметры запуска. Для изменения настроек он штатно закрывает Steam и затем открывает его снова. Не запускайте Steam вручную, пока идёт установка. Общие библиотеки могут временно быть заняты другими установщиками.

Если параметры запуска содержат сложную команду, которую нельзя безопасно дополнить, скрипт остановится и объяснит, как сохранить её и временно очистить поле. Не следует удалять свои настройки без копии.

### Если установка прервалась

Прочитайте сообщение об ошибке, выполните подсказку и повторите:

```bash
bash berserk-proton-fix.sh
```

Готовые компоненты не устанавливаются повторно. Незавершённая загрузка продолжается по сохранённому адресу Microsoft. Первый завершённый снимок исходного состояния не заменяется. Сохранённый вход при обычном повторе не удаляется.

**Если после обновления игры вход снова перестал работать, попробуйте повторно запустить установщик:**

```bash
bash berserk-proton-fix.sh
```

Steam мог заменить исправленную DLL исходной — в таком случае повторная установка может помочь. **Гарантии работы после обновлений нет:** разработчик может изменить плагин, его взаимодействие с игрой или способ авторизации. Старое исправление тогда может оказаться несовместимым; простая переустановка этого не устранит. Если проблема остаётся, не используйте патч с этой версией игры. Проверка файлов в Steam тоже может вернуть исходную DLL.

Снимок для полного отката относится к версии игры на момент первой установки. После обновления не возвращайте старую DLL вручную: она может не подойти новой версии игры.

Проверка окружения **без установки и изменения настроек**:

```bash
bash berserk-proton-fix.sh --check
```

Эта команда проверяет пути, инструменты и возможность подготовки настроек. Она не проверяет вход в аккаунт и не доказывает работоспособность игры.

## Полный откат

Закройте игру и выполните из папки со скриптом:

```bash
bash berserk-proton-fix.sh --uninstall
```

Команда возвращает:

- DLL, которая стояла перед первой установкой этой версии установщика;
- префикс Proton в исходное состояние; если его не было, удаляет созданный префикс;
- прежний выбор Proton и параметры запуска этой игры, не откатывая время игры и настройки других игр.

Затем она удаляет снимок состояния, журналы и кэш загрузки этого патча. Сам скачанный `.sh` можно удалить вручную.

**Вход и настройки, появившиеся после первой установки патча, при полном откате пропадут.** Исходный снимок может содержать данные входа — не публикуйте его. Если вы позднее изменили параметры запуска или Steam обновил DLL, откат может остановиться, чтобы не затереть новые данные. Следуйте сообщению; ничего не удаляйте наугад.

Proton и Steam Linux Runtime остаются: это общие инструменты Steam, которые могут использовать другие игры. Скрипт не удаляет сам Steam и игру. Ручные изменения и файлы, оставшиеся от более ранних способов установки до этого установщика, не входят в его снимок и не отменяются автоматически.

## Почему возникала ошибка

Окно входа в игре — веб-страница 4game в Microsoft WebView2. Исходный открытый плагин Unity создаёт её через `CreateCoreWebView2CompositionController`. На проверенном Proton этот вызов завершался `E_NOTIMPL` (`0x80004001`): необходимый путь DirectComposition не работал. На чистом префиксе также мог отсутствовать WebView2 или путь к Steam в реестре.

Доработанный плагин использует оконный `CreateCoreWebView2Controller` и показывает окно поверх игры. Для WebView2 включена программная отрисовка: `--disable-gpu --disable-gpu-compositing`. Это касается окна входа, а не графики самой игры. Фантомные щелчки и отключение песочницы не используются. Параметр `PROTON_USE_XALIA=0` отключает Xalia для этого запуска: в проверках его работа мешала окну WebView2.

## Что делает скрипт

1. Находит Steam, его библиотеки и игру по манифесту AppID, а не по фиксированной папке.
2. Выбирает официальный Proton 11.0. Берёт требуемый Steam Linux Runtime из манифеста Proton. Незавершённые загрузки не принимает за установленные компоненты.
3. Если подходящих инструментов нет, открывает их штатную установку через Steam. Не скачивает сторонние сборки Proton.
4. Закрывает Steam штатной командой, сохраняет исходную DLL, префикс и изменяемые настройки. Копия хранится в `steamapps/compatdata/.berserk-proton-fix-4926310` рядом с префиксом.
5. Назначает Proton в настройках Steam и добавляет параметр запуска для локальных пользователей Steam. Настройки других игр не меняет.
6. При необходимости запускает официальный установщик Microsoft WebView2 внутри префикса игры и через подходящий Steam Runtime. Загрузка идёт с серверов Microsoft по HTTPS, не из этого репозитория.
7. Добавляет пути Steam в реестр префикса и настройки совместимости WebView2, заменяет `WebView.dll` встроенной сборкой открытого плагина. Контрольная сумма встроенной DLL проверяется до замены.
8. Повторно использует готовые результаты и открывает Steam после завершения. При ошибке выводит причину, путь к журналу и команду отката.

Кэш находится в `$XDG_CACHE_HOME/berserk-proton-fix` или `~/.cache/berserk-proton-fix`. Для одного окружения сохраняется один установщик WebView2 размером не более 512 МиБ, до двух журналов Proton по 4 МиБ и один снимок префикса. Размер снимка зависит от состояния игры до установки; это не общий бэкап Steam. Папку `compatdata` не отправляйте вместе с отчётами об ошибках.

Это самостоятельная неофициальная доработка совместимости, не связанная с разработчиком игры, 4game, Valve или Microsoft. Она не добавляет игровых возможностей, не меняет баланс, ресурсы, основной исполняемый файл игры или серверную авторизацию и не обходит проверки доступа, оплату, DRM или античит.

При этом утверждать, что файлы игры вообще не меняются, было бы неверно: скрипт заменяет **открытый плагин `WebView.dll`**, а также меняет локальный префикс и настройки Steam. Оригинал сохраняется для отката. Саму игру, её ресурсы, Steam, Proton и установщик WebView2 этот репозиторий не распространяет.

Плагин основан на [gree/unity-webview](https://github.com/gree/unity-webview), исходник `plugins/Windows`, версия `1256c3849c`. Это изменённая сборка, не исходная версия плагина. Лицензия **zlib** разрешает изменение и распространение при сохранении уведомления об авторстве и обозначении доработок. Уведомление сохранено в `LICENSE.unity-webview`. Собственный код установщика и изменения распространяются по MIT (`LICENSE`). Права на игру и сторонние компоненты принадлежат их правообладателям. Их условия использования продолжают действовать; юридических гарантий совместимости с любыми условиями здесь нет.

## Использование и самостоятельная доработка

Проект выложен **как есть**. Гарантий, обязательств поддержки, проверки чужих сборок или приёма изменений нет. Это публикация найденного решения, а не сопровождаемый сервис. Если оно подходит — пользуйтесь. Если хотите изменить — сделайте fork и поддерживайте свою версию самостоятельно. Ответа на issue или рассмотрения pull request не обещается.

Для запуска нужен только один `.sh`: помощник и исправленная DLL встроены в него. Отдельная сборка не требуется. Если хотите изменить решение, можете самостоятельно изучить содержимое скрипта и исходный проект unity-webview. Не запускайте чужие доработанные скрипты, не просмотрев их код.
